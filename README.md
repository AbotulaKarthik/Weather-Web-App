# Weather-Web-App<br>
WeatherApp 🌦️<br>
This is a user-friendly web application that provides accurate and real-time weather updates <br>
for any location worldwide. Built using HTML, CSS, JavaScript.<br>
This app delivers a seamless experience for users to stay informed about the current weather conditions, forecasts, and more.<br>
🌟 Features <br>
- Real-Time Weather Updates: Access up-to-the-minute weather data. <br>
- Global Search: Get weather details for any city or location.<br>
- Interactive UI: A sleek, responsive design optimized for all devices.<br>
- Detailed Weather Data: Includes temperature, humidity, wind speed.<br>
🛠️ Built With <br>
- Frontend: HTML,CSS and JavaScript <br>
- API Integration: Powered by OpenWeatherMap API <br>
- Responsive Design: Ensures compatibility across desktop, tablet, and mobile devices. <br>
